## 4. L3 降级说明（框架硬规则 8 允许路径）

标准做法 Testcontainers 起独立 PG；本机 16GB 内存同时常驻 PG 容器 + Node + Metro，再起一个 5433 容器会挤占内存并可能与 5434 端口冲突。故 L3 采用「L2 打真实 HTTP + `docker exec rn-workout-pg psql` 直查真实 PG」，验证的仍是真实事务与真实约束，未使用 mock 替身。CI 无容器时 L3 整层 skip（不 failed），本地必跑。
