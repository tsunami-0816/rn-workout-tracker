## 5. 回滚步骤与代价

1. 把两份 `release.json` 的 `version` / `buildNo` / `apkUrl` 改回上一版本（例如 1.0.0 / 1 / `.../rn-workout-1.0.0.apk`）。
2. 保留旧 APK 不删；`/apk` 静态目录仍可下载。
3. 已装 1.0.2 / 1.0.1 的设备回滚到 1.0.0：
   - 首选：`adb install -r -d rn-workout-1.0.0.apk`（同签名允许降级）；
   - 无 adb：先卸载当前版本，再安装 1.0.0。
4. 代价：卸载会清掉 SecureStore 中的 token，需要重新验证码登录；训练记录在服务端，不受影响。
   改 `release.json` 回 1.0.0 后，已装 1.0.2 的设备冷启动会提示「发现新版本 1.0.0」并跳下载（版本号比较按 buildNo 降级不生效，属演示包已知行为）。
5. 不改签名、不改包名，回滚不需要重新构建。

## 6. 3 分钟演示脚本

1. 手机打开「训练台账」（已登录）→ 计划页，指出今天高亮的分化与「本周 N 次」。
2. 点今天的分化 → 任选第一个动作点「记录」→ 4 组各点一次「完成这组」，展示总容量累加。
3. 点「结束本次训练」→ 返回计划页，展示「已开练 / 本周 +1」、其余分化被锁到明天；再进记录页点一下组次，展示「已完成（已锁定）」+ 锁定提示（1.0.2 修的就是这里）。
4. 点「统计」→ 展示本周打卡天数、总容量、近 4 周柱状图、最近训练。
5. 点「我的」→ 展示 `v1.0.2 · build 3`、服务地址、SecureStore 登录凭据；admin 账号加看「管理后台」入口。
6. 升级演示：把 `release.json` 指向 1.0.2 后冷启动 App → 弹「发现新版本 1.0.2」→ 去下载 → 覆盖安装 → 登录态仍在。
