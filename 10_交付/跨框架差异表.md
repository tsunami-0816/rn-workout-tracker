# 跨框架差异表（RN / Expo ↔ Flutter）

> 口径：只写本轮两侧真实存在的事实；未验证的能力标「未验证」，不写成结论。
> 对象：RN 侧 `05_代码/frontend`（Expo 58 / RN 0.88）与 Flutter 侧 `05_代码/flutter`（Flutter 3.50.1 / Dart 3.14）。
> 证据：`09_验收/flutter_login.png`、`09_验收/flutter_list.png`；体积取各自构建产物的 `Measure-Object` 实测。

| # | 维度 | RN / Expo 事实 | Flutter 事实 | 结论差异 |
|---|---|---|---|---|
| 1 | 目录结构 | `src/screens`（7 屏）、`src/components`、`src/navigation`、`src/api`、`src/store`、`src/storage`、`src/theme`、`src/utils`；路由由 React Navigation 配置 | `lib/main.dart` 根状态 + `lib/api_client.dart` + `lib/screens/{login_page,list_page}.dart`；无独立路由库，用根 State 切页 | RN 分层更细；Flutter 两页把路由压到根 State，页面少时更直接 |
| 2 | 状态管理 | zustand（`authStore`/`toastStore`）+ TanStack Query 缓存请求 | 根 `StatefulWidget` 持有 token，页面内 `setState`；无请求缓存层 | Flutter 少了缓存/失效层；切计划每次真实请求，数据一致性更简单，请求量更大 |
| 3 | 列表渲染 | `FlatList` + `getItemLayout`（行高固定 64）+ `windowSize=7` + 100 条性能夹具 | `ListView.builder` + `itemExtent: 64`，12 条动作无虚拟化参数调整 | 都靠固定行高做布局复用；RN 有夹具压测入口，Flutter 本轮未做 100 条压测 |
| 4 | 网络层 | `src/api/client.ts`：8s 超时、GET 网络失败重试 1 次、仅 40101 清态、统一信封转中文 | `http` 包直接 POST/GET，无超时、无重试；只解析 `{code,message,data}`，非 0 抛中文 | Flutter 是「最小可用」版本，弱网治理明显少于 RN；对照点落在同契约而非同健壮度 |
| 5 | 登录与凭据 | 登录成功写 SecureStore（降级 AsyncStorage），冷启动 hydrate | 登录成功 token 只存内存，刷新页面需重新登录（页面已明示） | Flutter 缺持久化；这是本轮诚实边界，不是等价实现 |
| 6 | 打包与产物 | `eas.json` preview=APK；`expo export` 产物 `dist` 实测 **2.11 MB**（hbc 2.1 MB） | `flutter build web --release` 产物 `build/web` 实测 **40.21 MB**（含 CanvasKit 等运行时） | Web 形态下 Flutter 体积高一个量级；APK 体积两者本轮都未实测（Flutter 只构建 Web） |
| 7 | 运行时与构建命令 | `npm run start`（Metro 8096）/ `npm run build`（expo export）；dev 下 Fast Refresh | `flutter run -d chrome`（开发）/ `flutter build web`（发布）；修改后热重载 | 开发体验都支持热更新；本轮 Flutter 用 headless Edge 截图，未验证 `flutter run` 交互热重载 |
| 8 | 页面结构复用 | 设计 token（`theme/tokens.ts`：地面/墨色/强调色、8 倍间距）驱动 7 屏 | 同一套色值写进 Flutter 主题与组件（F4F5F2 / 14171A / 1D6B58），两页手工对齐 | 视觉语言一致；Flutter 侧未抽 token 常量，后续加页会重复 |

## 未覆盖 / 诚实边界

- Flutter 只构建 Web（`build/web`），**未构建 Android APK**：本机无 Android SDK，D-38~D-41 的 APK 仍走 RN 侧 EAS，Flutter 不参与打包对照。
- Flutter 未做持久化、未做 401 清态、未做超时重试：两页是「同契约的最小对照」，不宣称与 RN 功能等价。
- 截图来自 `--dart-define=DEMO_AUTOLOGIN=true` 的证据构建：自动登录只省去手输，登录仍走真实 `POST /auth/login`；最终交付构建已去掉该开关。
