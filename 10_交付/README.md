# rn-workout 交付包速览

> 训练台账 App：Expo/RN 客户端 + NestJS/PostgreSQL 后端。版本 **1.0.2 / build 3**。
> 完整部署与回滚见 `交付包与上线方案.md`；本文件只解决「5 分钟跑起来 + 3 分钟演示」。

## 1. 最快体验（已有 APK，不重新构建）

1. `docker compose up -d pg`（容器 `rn-workout-pg`，端口 5434）
2. `cd 05_代码\backend` → 复制 `.env.example` 为 `.env`（填 `JWT_SECRET`、`DEMO_CODE`）→ `npm ci` → `npx prisma migrate deploy` → `npm run seed` → `npm run build` → `npm run start:prod`
3. 手机与电脑同一 WiFi，浏览器打开 `http://<电脑IP>:8094/apk/rn-workout-1.0.2.apk` 安装
4. 登录：普通 `13900139000` / 验证码 `123456`；管理员 `13800138000` / `123456`
5. 自证：`http://<电脑IP>:8094/api/health` → `db:"up"`；`/api/app/version` → 1.0.2

> 一键版：项目根 `scripts\start_all.ps1`（起库→迁移→种子→构建→启动→health）；停服 `scripts\stop_all.ps1`（保留数据卷）。

## 2. 3 分钟演示脚本（C14）

| 时间 | 动作 | 讲解要点 |
|---|---|---|
| 0:00–0:20 | 冷启动 → 手机号 `13900139000` + 验证码 `123456` 登录 | 登录态用 SecureStore 持久化；异常码中文提示 |
| 0:20–0:50 | 计划页：推/拉/腿三卡 + 本周完成度；点「腿日」 | 今日（周三）腿日高亮；12 动作按序，行高固定 64 支撑长列表 |
| 0:50–1:40 | 开练 → 重量「+」两次、次数「+」一次 → 勾完成；再录 20kg×10 | 本地立即变化（乐观回填），容量 Σ(weight×reps)；同日重复开练复用同一 workout（幂等） |
| 1:40–2:00 | 结束训练 → 再点组次卡 | 成功提示；锁定态显示「已完成（已锁定）」并弹中文提示，不可再改（Q-009 回归点） |
| 2:00–2:30 | 统计页：本周天数 / 总容量 / 近 4 周柱状 | 与服务端一致；缓存 60s（`RN_CACHE=memory`） |
| 2:30–2:50 | 我的页：`139****9000`、普通用户、`v1.0.2 · build 3` | 手机号脱敏在服务端完成；版本行读 release.json |
| 2:50–3:00 | 管理员 `13800138000` 登录 → 我的 → 管理后台 | 普通号看不到入口；admin 只读全站打卡，手机号脱敏；越权 API 403/40301 |
