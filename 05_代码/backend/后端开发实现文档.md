## 3. 数据模型（5 表）

`prisma/schema.prisma` + `prisma/migrations/20261123092126_init/migration.sql`：

- `users`（id/phone 唯一/nickname/role user|admin/created_at）
- `plans`（user_id/sort_no/name/day_type push|pull|legs）
- `exercises`（plan_id/order_no/name/target_sets/target_reps）
- `workout_logs`（user_id/plan_id/log_date @db.Date/total_volume/finished_at）
- `set_logs`（workout_log_id/exercise_id/set_no/weight numeric(6,2)/reps/done，**唯一键 `uk_set_logs(workout_log_id, exercise_id, set_no)`**）

seed：`prisma/seed.ts` 幂等 upsert；本次实跑输出 `seed 完成：users=2 plans=6 exercises=72`。

## 7. 部署与启动

```
# 一次性
cp 05_代码/backend/.env.example .env  # 填 JWT_SECRET / DEMO_CODE
# 一条命令起全套（端口断言 → PG → migrate → seed → build → 起进程 → 探活）
& .\scripts\start_all.ps1
# 逆序关（停进程 + docker compose stop pg，保留数据卷）
& .\scripts\stop_all.ps1
```

- 端口：PG 5434 / 后端 8094 / Metro 8096（已在 `WORKFLOW_端口分配表.md` 登记）
- start_all 自带 `[0/5] env_preflight.py --ports 5434,8094,8096` 断言；端口被本项目自身占用按重启放行，被他人占用直接报红给 PID。
- pwsh 注意：docker / prisma / npm 会把进度写 stderr，脚本已用 `Invoke-Native` 包裹（只按退出码判成败），避免误报错中断。

## 10. 偏差与遗留

1. **Jest ESM**：NestJS 12 ESM-only，`npm test` 用 `node --experimental-vm-modules node_modules/jest/bin/jest.js`；CJS 模式会报 "Must use import to load ES Module"。（已落 `jest.config.js` / `tsconfig.spec.json`）
2. **start_all stderr**：pwsh 下 docker/prisma 的提示走 stderr 会被当 NativeCommandError；已用 `Invoke-Native` 包裹（首次实跑时确实中断过，修复后 exit 0）。
3. **未引 Redis**：统计缓存为进程内 60s Map（架构 §12 偏差 3），单实例演示够用，多实例需换 Redis。
4. **P1 遗留**：`05_代码/06.5_契约/openapi.json` 已与根目录 `06.5_契约/openapi.json` 重复，本轮清理只保留根目录一份（导出脚本按 `release.json` 向上找项目根）。
5. **不在本步范围**：EAS 构建 / APK 安装 / Flutter 两屏 / RN 六页 —— 5B 与 L7 处理。
